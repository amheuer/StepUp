# Mini Doodle Jump (Pygame)

This is a small Doodle Jump-like game written with Pygame. It's intentionally minimal and uses simple shapes so there are no external assets.

Requirements
- Python 3.8+
- pygame

Install pygame (recommended in a venv):

```bash
pip install pygame
```

Run the game:

```bash
python game.py
```

Controls
- Left / A: move left
- Right / D: move right
- R: restart after game over
- Esc / close window: quit

Enjoy!
